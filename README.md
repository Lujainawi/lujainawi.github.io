# Lujain Awidat — Personal Portfolio

## About

This personal portfolio website was created as part of a course preparation assignment. It presents:

- My background as a Computer Science student
- My main areas of interest: Backend, Frontend, and AI
- My work on a project in collaboration with NVIDIA
- My goals for the course
- Public contact links

## Features

- Hebrew content with right-to-left (RTL) support
- Responsive design for desktop, tablet, and mobile
- Personal “Soft Developer Notebook” visual style
- NVIDIA project snapshot
- Backend, Frontend, and AI areas of interest
- Accessible navigation and contact links
- Local avatar image
- No external libraries or dependencies

## Technologies

- HTML5
- CSS3
- Git
- GitHub Pages

## How to Run Locally

No dependency installation is required.

```bash
git clone https://github.com/Lujainawi/lujainawi.github.io.git
cd lujainawi.github.io
python3 -m http.server 8000
```

Open the website at `http://localhost:8000`.
